# Shopify表格生成 1.5 — 使用说明

自动上新流程中的「表格生成」环节：把供应商商品表 + 本地图片 → 上传到图床 → 生成上架表格。

---

## 一、怎么启动（免安装，双击即用）

这个包已经打包好，**不需要安装 Python、也不需要联网装任何库**。

1. 把整个文件夹拷到任意一台 Windows 电脑（Win10/Win11 均可）。
2. 双击 **`shopify.exe`**，弹出窗口即可用。

> 说明：`shopify.exe` 是自包含的单文件程序，运行时会自动解包，
> 并读取同目录的 `config.json` / `settings.json`。
> 所以 **exe 和这两个配置文件必须放在同一个文件夹**，不要单独把 exe 拷走。

---

## 二、窗口里怎么填

窗口上半部分是三个输入框，各点一次「选择」按钮：

| 输入框 | 选什么 |
|---|---|
| **数据表** | 供应商依赖表格（.xlsx） |
| **目标文件夹** | 放商品图片的文件夹 |
| **尺码文件夹** | 尺码表图片的文件夹 |

三个都选好后，点 **「开始」**。下半部分日志窗口会实时显示上传进度。

如果中途出错，界面会**弹窗提示**，同时把完整过程写进同目录的 `shopify_run.log`——把这个文件发回即可定位问题。

---

## 三、跑完得到什么

在**启动时所在目录**生成 `<目标文件夹名>.xlsx`。

结果文件里**只有 Sheet1 一张表**，53 列 TEMU 上架格式：

- 每个 SKU 一行
- `SKU货号` = 图片名前缀 + `-` + 该行的「变种属性值二」
  （例：`DJLLWY-MDL26050801-1.jpg` → `DJLLWY-MDL26050801-5-6Y`）
- 多张图片用 `|` 连接，写在「轮播图」「产品素材图」「SKC属性.previewImgUrls」
- `SKC属性` 里的 `extCode` = 该行的 SKU货号值

## 四、图片上传到哪（默认公共图床优先）

| 优先级 | 目标 | 说明 |
|---|---|---|
| **优先** | 公共图床（iili.io 等） | 公网可访问，表格里写这个地址 |
| 回退 | 工厂图床 `218.65.17.106:4999` | 公共图床全失败时才用 |

公共图床有多家容灾，按顺序尝试：**FreeImage → BeeIMG → Uguu → BeeIMG-CN**，
谁家抽风就自动换下一家；上传前自动压缩（长边 1200px），失败按类型重试。

### 想改上传策略

编辑同目录的 **`settings.json`**（这个文件不会被 WPS 锁住，随时可改）：

```json
{ "upload_target": "public_first" }   // 公共图床优先，失败回退工厂（默认）
{ "upload_target": "public" }         // 只传公共图床
{ "upload_target": "factory" }        // 只传工厂图床
{ "upload_target": "both" }           // 两者都传
```

`config.json` 是原版自带的老配置（厂名 + 工厂图床地址），保持不动即可。

> 如果其他主机要用**不同的工厂图床地址**，改 `config.json` 里的 `host` 即可；
> 如果这个文件被 Excel/WPS 锁住改不了，把新地址写进 `settings.json` 也能覆盖。

## 五、目录约定

```
目标文件夹/
└── 款号/                    ← 可省略，程序会从图片名反推款号
    └── parent_sku/          ← 这一层是款式名，会写进「产品标题」
        ├── 商品图1.jpg      ← 文件名格式：<SKU前缀>-<序号>.jpg
        ├── 商品图2.jpg
        └── 通用图片/         ← 可选，里面的图当公用详情图
            └── 详情.jpg
```

图片名前缀 `DJLLWY-MDL26050801` 用来生成 SKU货号；
前缀第一段 `DJLLWY` 是款号，用来匹配数据表「依赖文件」。

---

## 六、文件夹里都有什么

| 文件 | 作用 |
|---|---|
| `shopify.exe` | 主程序（自包含，双击即用） |
| `config.json` | 厂名 + 工厂图床地址（原版配置） |
| `settings.json` | 上传策略等新配置（可随时改） |
| `使用说明.md` | 本说明 |
